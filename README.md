# 小櫻讀書計劃表 — 完整使用指南

**小櫻讀書計劃表** 是一個純前端、離線優先（Local-First）的日系編輯器級 80 天衝刺讀書規劃與專注計時工作區（PWA）。
免註冊、免登入帳號，支援手機與電腦打開網址即刻同步所有讀書紀錄。

* **線上部署網址**：`https://yikai02.github.io/sakura-study-planner/?room=sakura-study-2026`
* **專案版次**：`v2.4.0`（Editorial Workspace ＋ 5 款日系穿搭布料主題）

---

## 一、介面架構總覽：48px 頂部狀態列 ＋ 非對稱雙欄

為了讓長時間備考減少視覺壓迫，畫面取消繁複卡片邊框與高飽和標籤，改為「左側專注控制欄 ＋ 右側主工作畫布」的非對稱雙欄與 `1px` 極細格線排版：

### 1. 48px 頂部極簡狀態列（Top Bar）
* **左側 Breadcrumb 路徑**：顯示目前的 `[房間代碼] / [讀書計畫主標題]`。
  * 點擊房間代碼 pill 可快速開啟跨裝置連線與備份設定視窗。
  * 直接點擊主標題即可 **原地重新命名**，系統會即時儲存並同步至其他裝置。
* **中央浮動專注橫幅**：開始計時後自動呈現，顯示目前專注科目、歸屬時段與等寬碼錶，方便隨時在任意分頁控制 `暫停`、`結束` 或 `查看`。
* **右側控制區**：
  * **同步狀態微圓點**：綠點代表即時連線同步，琥珀色代表同步中，灰點代表離線純本機模式（可照常紀錄）。
  * **5 款日系穿搭布料主題圓點**：一鍵切換工作區色調，偏好會記憶於本機 `localStorage`。
  * **系統設定按鈕（齒輪）**：調整布料主題、考試日期、目標時數、衝刺三階段區間，以及備份 / 匯出功能。

## 三、左側專注計時與「科目實體」清單

左側欄固定顯示目前衝刺進度與即時碼錶（手機等窄螢幕下可從分頁列切換至 `專注計時`）：

### 1. 衝刺倒數進度條
* 即時顯示距離目標考試日剩餘天數（`D-XX`）與 80 天期程進度條。

### 2. 即時專注碼錶（嚴格綁定真實時間）
* **模式切換**：支援 **正計時**、**番茄 25m**、**深度 50m**。
* **固定歸屬當下時刻**：無論右側正在瀏覽或編輯行事曆哪一天，按下計時一律鎖定「當下真實時刻」，不會誤寫入過去或未來日期；點擊 `切回今日` 可一鍵回到今日狀態，點擊 `展開大表` 會自動捲動至右側大表的今日列。
* **凌晨 05:00 換日與開始時間判定規則**：
  * **早上時段**：`05:00 ~ 12:00`
  * **下午時段**：`12:00 ~ 19:00`
  * **晚上時段**：`19:00 ~ 05:00`（跨午夜至隔日凌晨 04:59 皆歸屬於同一讀書日與晚上時段）
  * **以開始時間為唯一依據**：例如 09:30 開始讀書直到 13:15 結束，該筆紀錄仍完整歸入「早上時段」。
  * **凌晨 05:00 跨夜保護**：若於凌晨 05:00 前僅按下 `暫停` 而忘記按 `結束紀錄`，跨過換日線後系統會自動結算並歸檔該筆專注紀錄。
* **背景防漏算與「休息時間」**：
  * 計時中將手機鎖屏或關閉瀏覽器，重開後透過毫秒時間戳補齊經過時間。
  * 按下 `暫停` 或 `結束紀錄` 後，下方「休息時間」區塊即時開始計算本次離開座位的休息秒數。

### 3. 6 大科目實體與全域色票連動
* 內建 6 個預設科目：**個經、總經、統計、財管、上課、其他**（可依個人需求重新命名）。
* **6 款時裝布料色票**：點擊科目左側的圓點，可展開色票盤自由指定：
  * 煙燻玫瑰 `#9E6B70`
  * 冷調丹寧 `#52687D`
  * 橄欖軍綠 `#6D7864`
  * 焦糖麂皮 `#A67B5B`
  * 水泥冷灰 `#7A7D80`
  * 深焙可可 `#6E5A53`
* **全域連動**：在左側修改任一科目名稱或更換代表色票時，專注計時器、右側「每日專注大表」織標、Notion 行事曆與「統計分析」中的同名科目全部即時連動更新，且原有時數紀錄完整保留。

## 四、全域原地編輯（Inline Rename）

* 畫面中所有帶有 hover 微霧底色的標題與名稱皆支援 **Click-to-Edit 原地編輯**：
  * 頂部讀書計畫主標題
  * 左側欄與右側四個分頁的區塊副標題
  * 左側科目清單中的科目名稱
* **操作方式**：
  1. 滑鼠移上標題時會浮現淺色微底框提示可編輯。
  2. 直接點擊文字立即轉為無邊框輸入框。
  3. 按下 `Enter` 或點擊其他空白處（失焦）即自動儲存並廣播同步；按 `Esc` 則取消還原。

## 五、右側四大檢視分頁教學

### 1. 【每日專注】大表（預設主頁 — 服裝織標視圖）
* **6 欄清晰大表**：`日期 / 早上 / 下午 / 晚上 / 當日總計 / 備忘`，所有時間與累計數值採用 `JetBrains Mono` 等寬對齊數字。
* **服裝織標（Woven Label）**：每個專注時段皆以左側 `3px` 科目代表色邊條搭配同色系低飽和霧面底色呈現。版面預設僅顯示「科目名稱」與「等寬時長」，一眼掃讀全期節奏。
* **Hover 浮層詳情**：將滑鼠游標停留在任一織標上，即會展開極簡浮層顯示該時段任務內容、起訖時間與休息狀況。
* **點擊開啟編輯**：點擊任一日期或織標區塊，立即彈出當日快捷編輯視窗；上方提供衝刺階段篩選、科目篩選、關鍵字搜尋與 `捲動至今日` 快速定位。

### 2. 【行事曆】Notion 風格月曆 ＋ 當日快捷頁面
* 上方支援月份切換與關鍵字搜尋（非相關日期自動淡化凸顯重點）。
* 每個日期格內可直接切換 `[早] / [午] / [晚]` 科目並就地輸入今日單元。
* **Notion 當日快捷頁面（Modal）**：點擊月曆上的日期數字列或今日概覽入口，會在畫面中央開啟純淨的當日快捷頁面，專注檢視與修改「重要備忘錄」、三時段「科目 / 工作說明 / 開始與結束時間 / 時數 / 完成勾選」，不夾帶干擾計時按鈕；支援前一天、跳至今日、後一天快捷切換與 `Esc` 關閉。

### 3. 【今日概覽】
* **編輯封面背板**：點擊右下角「更換背板」，可選擇內建漸層或上傳自訂背景圖片（支援上下移動或縮放）。
* **今日 KPI 與三時段清單**：一眼檢視今日累計時數、完成時段與距離 80 天期程位置，並可直接修改今日各時段科目、進度勾選與備忘。

### 4. 【統計分析】
* **指標總覽**：總專注時數、完成時段總數、平均每日專注時間、距離目標達成率。
* **早中晚作息分佈條**：量化統計三個時段的精力分配比例。
* **核心科目統計與階段進度表**：自動彙整經濟（含個經／總經）、統計、財管、上課與各衝刺階段的實際投入與目標比例。

## 六、跨裝置同步、備份與常見問題

### 跨裝置同步機制
* 只要多台設備開啟相同 `?room=房號` 網址（預設為 `sakura-study-2026`），即會在免帳號狀態下建立加密即時同步。
* 點擊頂欄左上角房號 pill 或右上角連線圓點，即可查看 **QR Code**（手機掃描即刻加入）或複製分享連結。
* **防覆蓋合併（Conflict-Free）**：每筆時段資料、科目名稱與主副標題皆以毫秒時間戳 `updatedAt` 判斷新舊，確保離線編輯重新連線後不會被舊裝置資料覆蓋；專案亦搭配 GitHub Actions 定時快照備份腳本（`scripts/keepalive-backup.py`）。

### 常見問題（FAQ）
**Q1：更換主題或重新命名科目後，以前記下的讀書時數會不見嗎？**
> 不會。所有既有的 80 天讀書紀錄（`sakura_study_planner_v1`）、自訂封面與房號狀態皆 100% 保留；科目採用穩定 `id` 與名稱對照連動，更名與換色僅更新顯示與統計彙整。

**Q2：如果忘記停止計時，隔天早上打開怎麼辦？**
> 系統每天以 `05:00` 作為換日邊界。若在 `05:00` 前處於暫停未結束狀態，跨日後會自動結算並歸入前一個讀書日的對應時段。

**Q3：離線（如圖書館地下室無網路）可以使用嗎？**
> 可以。所有操作最優先儲存於本機瀏覽器 `localStorage` 與 PWA 快取（Service Worker），恢復網路連線後會自動透過時間戳合併並同步最新進度。
